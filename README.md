# SML Projects

Four Standard ML projects from an undergraduate Programming Languages
course (IIT Delhi, COL226), covering parsing, arbitrary-precision/rational
arithmetic, and two different ways of executing an imperative language
(tree-walking interpretation vs. a stack-based virtual machine).

| Project | What it is |
|---|---|
| [markup-to-html](markup-to-html) | Hand-written translator from a Markdown-like format to HTML |
| [rational-numbers](rational-numbers) | Arbitrary-precision integer + exact rational number library and parser |
| [rational-pl0-interpreter](rational-pl0-interpreter) | Tree-walking interpreter for an imperative language with rational numbers, built with ML-Lex/ML-Yacc, using the library above |
| [while-vm](while-vm) | Stack-based virtual machine for the same language, as an alternative to tree-walking |

Each project is self-contained (own `README.md`, own `docs/` with the
assignment brief where available).
